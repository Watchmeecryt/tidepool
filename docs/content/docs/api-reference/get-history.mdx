<p><span className="tp-method tp-get">GET</span><code>{"/v0/account/history"}</code></p>

Needs `Authorization: Bearer <accessToken>`. Lists swaps where the account is the `recipient`, `refundTo`, sender or signer, newest first. Real response for a throwaway account that created two quotes (a swap quote and an order).

Returns paginated public and confidential transaction history. History is invite-only for now. For the initial request, omit both nextCursor and prevCursor to retrieve the latest history. For subsequent requests, pass either nextCursor or prevCursor from the previous response. Tidepool: needs a Tidepool JWT. Swaps where you are the refund address or recipient, newest first, with cursor paging.

**Operation id:** `getHistory`

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl "https://www.usetidepool.tech/v0/account/history" \
  -H 'Authorization: Bearer <accessToken>'
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/account/history', {
  headers: { 'Authorization': 'Bearer <accessToken>' },
});
const data = await res.json();
```

</Tab>
</Tabs>

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `prevCursor` | string |  | Pass the prevCursor value from a previous response to fetch older items. Omit both cursors for the initial request. Do not pass together with nextCursor. |
| `nextCursor` | string |  | Pass the nextCursor value from a previous response to poll for newer items. Omit both cursors for the initial request. Do not pass together with prevCursor. |
| `status` | "PENDING_DEPOSIT" \| "INCOMPLETE_DEPOSIT" \| "PROCESSING" \| "SUCCESS" \| "REFUNDED" \| "FAILED"[] |  | Filter by statuses |
| `limit` | integer |  | Maximum number of items to return per page |
| `depositAddress` | string |  | Filter by deposit address |
| `depositMemo` | string |  | Filter by deposit memo. Only has effect when depositAddress is also provided. |
| `search` | string |  | Search by deposit address, recipient, sender, or tx hash |
| `depositType` | "ORIGIN_CHAIN" \| "INTENTS" \| "CONFIDENTIAL_INTENTS" \| "null"[] |  | Correlated deposit type filter. Index-aligned with recipientType and refundType. Use "null" as a wildcard for that position. Multiple values form OR conditions. |
| `recipientType` | "DESTINATION_CHAIN" \| "INTENTS" \| "CONFIDENTIAL_INTENTS" \| "null"[] |  | Correlated recipient type filter. Index-aligned with depositType and refundType. Use "null" as a wildcard for that position. |
| `refundType` | "ORIGIN_CHAIN" \| "INTENTS" \| "CONFIDENTIAL_INTENTS" \| "null"[] |  | Correlated refund type filter. Index-aligned with depositType and recipientType. Use "null" as a wildcard for that position. |

### 401 Unauthorized - supplied user session token is invalid or expired

```json
{
  "message": "Unauthorized: send Authorization: Bearer <accessToken> from /v0/auth/authenticate"
}
```

### 403 History is invite-only for now

Tidepool does not return this: history is open to every authenticated account on testnet.
