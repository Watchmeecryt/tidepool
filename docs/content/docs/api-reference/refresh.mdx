Send the `refreshToken` from `/v0/auth/authenticate`. Real request and response (throwaway account).

Exchange refresh token for a new access token Tidepool: exchanges a refresh token for a new access token.

**Operation id:** `refresh`

### Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `refreshToken` | string | yes | Refresh token obtained from authenticate endpoint |
