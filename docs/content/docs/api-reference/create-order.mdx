<p><span className="tp-method tp-post">POST</span><code>{"/v0/orders"}</code></p>

Needs `Authorization: Bearer <accessToken>` (or any `X-API-Key`). Tidepool fills a limit order once, with no partial fills; deadline 7 days by default and 30 days at most. The request sets every attribute; real response (a SELL of 1 wNEAR at 3.5 USDC, deposit not yet made, so `AWAITING_DEPOSIT`).

Creates a confidential order. **Errors.** Branch on `code`, never on `title` or `detail`. New codes arrive without a major version, so treat an unrecognized code as the HTTP status alone. \| Status \| Codes \| \| --- \| --- \| \| 400 \| `malformed-request`, `validation-failed`, `request-rejected`, `order-rejected` \| \| 401 \| `authentication-required` \| \| 403 \| `client-generated-id` \| \| 409 \| `resource-type-mismatch` \| \| 429 \| `rate-limit-exceeded` \| \| 500 \| `internal-error` \| \| 503 \| `service-unavailable` \| Tidepool: needs a Tidepool JWT or any X-API-Key. The Tidepool maker fills the whole order once (no partial fills). SELL fills at the limit price. `confidentiality` is ignored. The deadline defaults to 7 days, max 30.

**Operation id:** `createOrder` · **Auth:** optional (`X-API-Key` or `Authorization: Bearer`, any value)

| `data.attributes.quoteAsset` | string | yes | ID of the quote asset used to price the base asset. |

| `data.attributes.refundTo` | string | yes | Address used for refunds. |
| `data.attributes.refundType` | object | yes | Type of refund address. |
| `data.attributes.recipient` | string | yes | Address or Intents account that receives successfully filled output. |
| `data.attributes.recipientType` | object | yes | Type of recipient address. |
| `data.attributes.deadline` | string |  | Timestamp in ISO format that identifies when the order can expire. |
| `data.attributes.depositMode` | object |  | Deposit address mode. |
| `data.attributes.confidentiality` | object | yes | Confidentiality mode. Required for orders. |
| `data.attributes.timeInForce` | object |  | Time in force for the order. |
| `data.attributes.appFees` | AppFee[] |  | Application fees included in the submitted limit price and deducted from input. |
| `data.attributes.appFees[].[]recipient` | string | yes | Account ID within Intents to which this fee will be transferred |
| `data.attributes.appFees[].[]fee` | number | yes | Fee for this recipient as part of amountIn in basis points (1/100th of a percent), e.g. 100 for 1% fee |
