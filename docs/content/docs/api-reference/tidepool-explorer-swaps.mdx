<p><span className="tp-method tp-get">GET</span><code>{"/v0/explorer/swaps"}</code></p>

<Callout title="Tidepool extension">This endpoint is not part of the 1Click API. Do not call it on mainnet.</Callout>

Read-only list of funded swaps (a deposit was seen), newest first, as shown on https://www.usetidepool.tech/explorer. Unpaid quotes and simulate test fixtures are excluded. No auth. Rate limit: 120 requests per minute per IP across /v0/explorer/*.

**Operation id:** `TidepoolExplorerSwaps`

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl "https://www.usetidepool.tech/v0/explorer/swaps"
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/explorer/swaps');
const data = await res.json();
```

</Tab>
</Tabs>

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `page` | integer |  | 1-based page. |
| `limit` | integer |  | Rows per page (1-100). |
| `status` | "SUCCESS" \| "PROCESSING" \| "KNOWN_DEPOSIT_TX" \| "INCOMPLETE_DEPOSIT" \| "REFUNDED" \| "FAILED" |  | Only swaps with this status. |
| `chain` | string |  | Only swaps with this chain on either side (near, eth, base, arb, bsc, sol, stellar, sui, xrp, btc, zec, hypercore). |
| `search` | string |  | Case-insensitive match on deposit address, sender, recipient, token symbol or tx link. |
