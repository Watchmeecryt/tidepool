<p><span className="tp-method tp-get">GET</span><code>{"/v0/orders"}</code></p>

Needs `Authorization: Bearer <accessToken>` (or any `X-API-Key`); lists only your own orders. Real response, taken right after creating the order in the create-order example.

Retrieves visible orders, newest first. **Errors.** Branch on `code`, never on `title` or `detail`. New codes arrive without a major version, so treat an unrecognized code as the HTTP status alone. \| Status \| Codes \| \| --- \| --- \| \| 400 \| `validation-failed` \| \| 401 \| `authentication-required` \| \| 429 \| `rate-limit-exceeded` \| \| 500 \| `internal-error` \| \| 503 \| `service-unavailable` \| Tidepool: cursor paging with `page[size]` and `page[cursor]`; `links.next` and `meta.nextCursor`.

**Operation id:** `listOrders` · **Auth:** optional (`X-API-Key` or `Authorization: Bearer`, any value)

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl "https://www.usetidepool.tech/v0/orders" \
  -H 'Authorization: Bearer <accessToken>'
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/orders', {
  headers: { 'Authorization': 'Bearer <accessToken>' },
});
const data = await res.json();
```

</Tab>
</Tabs>
