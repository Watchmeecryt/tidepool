<p><span className="tp-method tp-get">GET</span><code>{"/v0/explorer/stats"}</code></p>

<Callout title="Tidepool extension">This endpoint is not part of the 1Click API. Do not call it on mainnet.</Callout>

Totals for the explorer header: funded swaps by status, successful volume in USD (testnet prices), last 24 hours, unique addresses and swaps per chain. No auth; same rate limit as /v0/explorer/swaps.

**Operation id:** `TidepoolExplorerStats`

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl "https://www.usetidepool.tech/v0/explorer/stats"
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/explorer/stats');
const data = await res.json();
```

</Tab>
</Tabs>
