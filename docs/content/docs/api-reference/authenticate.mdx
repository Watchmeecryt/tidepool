<p><span className="tp-method tp-post">POST</span><code>{"/v0/auth/authenticate"}</code></p>

The example signs with a throwaway ed25519 key (`raw_ed25519`); the account id is the key's 64-hex implicit account. The `payload` is a JSON string with `signer_id`, `verifying_contract`, `deadline`, `nonce` and `intents`. For `nep413` the same fields go in `payload.message` with `payload.nonce` (base64) and `payload.recipient`. The tokens below are real and expire (access token 1 hour), and belong to a throwaway account with no funds.

Verifies wallet signature and issues session tokens Tidepool: free JWTs (HS256, access 1 h, refresh 30 d), valid on Tidepool only. Supported standards: nep413, raw_ed25519, erc191. The key must belong to the signer (NEAR implicit account, a NEAR access key, or a key registered on the verifier).

**Operation id:** `authenticate`
