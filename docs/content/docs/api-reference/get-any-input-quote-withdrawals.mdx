<p><span className="tp-method tp-get">GET</span><code>{"/v0/any-input/withdrawals"}</code></p>

Retrieves all withdrawals by ANY_INPUT quote with filtering, pagination and sorting Tidepool: `withdrawals` is the spec's single object (the newest on the page). The full page is also returned as `tidepool.withdrawals` with `total`, `page` and `limit`.

**Operation id:** `getAnyInputQuoteWithdrawals` · **Auth:** optional (`X-API-Key` or `Authorization: Bearer`, any value)

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl "https://www.usetidepool.tech/v0/any-input/withdrawals"
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/any-input/withdrawals');
const data = await res.json();
```

</Tab>
</Tabs>

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `depositAddress` | string | yes |  |
| `depositMemo` | string |  |  |
| `timestampFrom` | string |  | Filter withdrawals from this timestamp (ISO string) |
| `page` | number |  | Page number for pagination (default: 1) |
| `limit` | number |  | Number of withdrawals per page (max: 50, default: 50) |
| `sortOrder` | "asc" \| "desc" |  | Sort order |
