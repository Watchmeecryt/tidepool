<p><span className="tp-method tp-get">GET</span><code>{"/v0/any-input/withdrawals"}</code></p>

Real response for a live `ANY_INPUT` quote that has not received a deposit yet, so `tidepool.withdrawals` is empty. After deposits, each payout appears as an entry of `tidepool.withdrawals` (and the newest one in the top-level fields, as in 1Click); see the fields table.

Retrieves all withdrawals by ANY_INPUT quote with filtering, pagination and sorting Tidepool: `withdrawals` is the spec's single object (the newest on the page). The full page is also returned as `tidepool.withdrawals` with `total`, `page` and `limit`.

**Operation id:** `getAnyInputQuoteWithdrawals` · **Auth:** optional (`X-API-Key` or `Authorization: Bearer`, any value)

## Request

```bash
curl "https://www.usetidepool.tech/v0/any-input/withdrawals?depositAddress=1479dfce6931f61456a8abdac46f04574da520d5f71313339c292fda1be950f7"
```

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `depositAddress` | string | yes |  |
| `depositMemo` | string |  |  |
| `timestampFrom` | string |  | Filter withdrawals from this timestamp (ISO string) |
| `page` | number |  | Page number for pagination (default: 1) |
| `limit` | number |  | Number of withdrawals per page (max: 50, default: 50) |
| `sortOrder` | "asc" \| "desc" |  | Sort order |

## Responses

### 200 

```json
{
  "asset": "nep141:wnear.tidepool-sandbox.testnet",
  "recipient": "user.testnet",
  "affiliateRecipient": "",
  "tidepool": {
    "withdrawals": [],
    "total": 0,
    "page": 1,
    "limit": 50
  }
}
```

### 401 Unauthorized - API key or JWT token is invalid

Tidepool does not return this: `/v0/any-input/withdrawals` takes no authentication.

### 404 Deposit address not found

```json
{
  "message": "Deposit address not found"
}
```
