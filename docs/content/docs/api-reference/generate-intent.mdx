<p><span className="tp-method tp-post">POST</span><code>{"/v0/generate-intent"}</code></p>

Only for quotes with `depositType: INTENTS` (the deposit address is an intents account). The `intent.payload` is the exact string to sign; sign it with your wallet and send the result to `/v0/submit-intent`. The `deadline` in the payload is about 15 minutes ahead. Real request and response from a live quote.

Generates an unsigned intent payload that needs to be signed by the user.   This endpoint takes a quote or limit-order deposit address, validates the target state and caller ownership when required, and returns an intent payload formatted according to the specified signing standard (e.g., NEP413, ERC191).   The generated intent must be signed by the user's wallet and then submitted via the `/submit-intent` endpoint to complete the action (e.g. swap).   **Request Type Variants:**   - `swap_transfer`: Generate an intent for a swap operation (requires depositAddress, signerId, standard) Tidepool: only quotes with depositType INTENTS can be funded this way. Supports nep413, raw_ed25519, erc191, tip191 and sep53. webauthn and ton_connect are accepted by submit-intent but cannot be generated.

**Operation id:** `generateIntent` · **Auth:** optional (`X-API-Key` or `Authorization: Bearer`, any value)

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl -X POST "https://www.usetidepool.tech/v0/generate-intent" \
  -H 'content-type: application/json' \
  -d '{
  "type": "swap_transfer",
  "standard": "raw_ed25519",
  "signerId": "9cf39ad040a13205c3ab109a8566fd779394a548f76b1aed5107efcdfe6c7ceb",
  "depositAddress": "54e8db801fab4ec416719b8b3044c21bacb4652c698ad4c5846086e5cf27b3a4"
}'
```

</Tab>

### Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | "swap_transfer" | yes | The type of intent action |
| `standard` | object | yes | The standard used for signing the intent |
| `signerId` | string | yes | The account ID of the signer |
| `depositAddress` | string | yes | The deposit address from the quote response |

### 400 Bad Request - Invalid input or quote state

```json
{
  "message": "type must be swap_transfer"
}
```

### 401 Unauthorized - API key or JWT token is invalid

Tidepool does not return this: `/v0/generate-intent` takes no authentication.
