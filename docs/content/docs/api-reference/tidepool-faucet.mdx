<Callout title="Tidepool extension">This endpoint is not part of the 1Click API. Do not call it on mainnet.</Callout>

The faucet is **site-only**. Direct API calls answer **403 `site_only`**; claim at https://app.usetidepool.tech/faucet (or the widget on the [Faucet](/docs/guides/faucet) page). The request body below is what the site sends.

Limits: one Tokens claim per address every 7 days across all non-Ondo variants, plus a separate Stocks & RWAs slot (up to 5 Ondo tokens on BSC Testnet) every 7 days; 2 claims per IP every 24 hours. Other chains: send `{"chain":"base","address":"0x…"}` (also eth, arb, bsc, sol, stellar, sui; btc and xrp answer 400 with the external faucet to use, since native BTC and XRP are never dripped). On BSC, `assets:["ondo"]` or specific symbols (max 5) drip Stocks & RWAs. Bridged tokens into the verifier: `{"accountId":"alice.testnet","mode":"intents","assets":["sol"]}`. In `wallet` mode `drips` has one entry and `transactions` one transaction per token (all six NEAR test tokens by default); in `intents` mode the transfer is batched into one transaction per six tokens. The 200 sample below was recorded from a live `wallet` drip and is **shortened**: it lists two of the six tokens in `drips` and only the first mint in `transactions`. A full response lists every token (one `transactions` entry per token in `wallet` mode). See [Faucet](/docs/guides/faucet).

The faucet is site-only. Direct API calls (curl, agents, scripts) answer 403 site_only; claim test tokens at https://app.usetidepool.tech/faucet (or the faucet widget on the docs). The body below is what the site sends. NEAR (no chain): pass accountId; mode=wallet mints the six NEP-141 test tokens to the account; mode=intents credits them inside the Tidepool verifier. With mode=intents, assets also accepts chain aliases (sol, stellar, sui, base, arb, eth, bsc, bridged) that credit that chain's bridged test tokens to the intents balance: USDC and USDT 100 each, plus verifier-only test SOL (0.05) for sol and test XLM (5) for stellar and test SUI (0.5) for sui. Other chains: pass chain (eth, base, arb, bsc, sol, stellar or sui) and the address on that chain to send 100 test USDC and 100 test USDT there (ERC-20, SPL with token accounts created for you, Stellar classic assets, or Sui Move coins (no setup, any address); Stellar needs an existing account with trustlines to issuer GDXABUSRHP4YA5CELHLNJQ4M3TX2BSJ6PEMDFCG2RA4PQLAQLRMFFQAN). On BSC, assets:["ondo"] or specific symbols (max 5) drip Ondo tokenized stocks/RWAs instead of USDC/USDT; that Stocks & RWAs claim has its own 7-day slot, separate from the Tokens slot. Native gas (ETH, tBNB, SOL, XLM, SUI) is never dripped: use each chain's own faucet. Native BTC (testnet4) and native XRP are never dripped either: chain btc and chain xrp answer 400 and name the external faucet (CypherFaucet / testnet4.info for BTC, the official XRPL testnet faucet faucet.altnet.rippletest.net for XRP). Eligibility: NEAR accounts must exist and be at least 24 hours old; EVM addresses must have sent a transaction or hold a native balance on Ethereum Sepolia, or on BSC Testnet for chain=bsc (403 otherwise). Limits: one Tokens claim per address every 7 days across all non-Ondo variants, plus one separate Stocks & RWAs claim per address every 7 days; 2 claims per IP every 24 hours (429). If the server enables Cloudflare Turnstile, the site sends turnstileToken (or an naa_ API key).

**Operation id:** `TidepoolFaucet`

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl -X POST "https://www.usetidepool.tech/v0/faucet" \
  -H 'content-type: application/json' \
  -d '{
  "accountId": "alice.testnet",
  "mode": "wallet"
}'
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/faucet', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({
    "accountId": "alice.testnet",
    "mode": "wallet"
  }),
});
const data = await res.json();
```

</Tab>
</Tabs>

### Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `accountId` | string |  | NEAR testnet account. Required unless chain/address are set. |
| `mode` | "wallet" \\| "intents" |  |  |
| `assets` | string[] |  | Optional subset: asset ids, NEAR symbols, or (mode=intents) chain aliases sol, stellar, sui, base, arb, eth, bsc, bridged (btc and xrp are accepted but give nothing: native BTC and XRP are never dripped). On chain=bsc, "ondo" or up to 5 Ondo symbols (AAPLon, TSLAon, ...) drip Stocks & RWAs (separate 7-day slot). Default: the six NEAR tokens. |
| `chain` | "base" \\| "arb" \\| "eth" \\| "bsc" \\| "sol" \\| "stellar" \\| "sui" |  | Chain to drip USDC and USDT on (Base Sepolia, Arbitrum Sepolia, Ethereum Sepolia, BSC Testnet, Solana devnet, Stellar testnet, Sui testnet). Omit for NEAR. On bsc, assets:["ondo"] or specific symbols (max 5) drip Ondo Stocks & RWAs instead. btc and xrp are not drip chains: they answer 400 with the external faucet to use (native BTC and XRP are never dripped). |
| `address` | string |  | Address on that chain: 0x… (eth, base, arb), base58 (sol), G… (stellar) or 0x + 64 hex (sui). Required with chain. |

## Responses

### 200 Drip sent

```json
{
  "accountId": "alice.testnet",
  "mode": "wallet",
  "drips": [
    {
      "assetId": "nep141:usdc.tidepool-sandbox.testnet",
      "symbol": "USDC",
      "amount": "100"
    },
    {
      "assetId": "nep141:usdt.tidepool-sandbox.testnet",
      "symbol": "USDT",
      "amount": "100"
    }
  ],
  "transactions": [
    {
      "assetId": "nep141:usdc.tidepool-sandbox.testnet",
      "amount": "100",
      "txHash": "F6JiEXj2LSkzhAdGoBV5hBs5etTjdgNvvNsH72aBACcN",
      "explorerUrl": "https://testnet.nearblocks.io/txns/F6JiEXj2LSkzhAdGoBV5hBs5etTjdgNvvNsH72aBACcN"
    }
  ]
}
```

### 400 Bad request

```json
{
  "message": "accountId must be a NEAR testnet account id"
}
```

### 403 Direct API calls answer 403 site_only (claim on https://app.usetidepool.tech/faucet). Also used when the address is not eligible (account_not_found, account_too_new, address_inactive) or captcha is required/failed.

No real example was recorded for this status code.

### 429 Rate limited

```json
{
  "message": "Rate limited: alice.testnet can use the faucet again after 2026-11-07T12:00:00.000Z (one claim per address every 7 days).",
  "available_at": "2026-11-07T12:00:00.000Z",
  "retryAfter": "2026-11-07T12:00:00.000Z",
  "retryAfterSeconds": 604800
}
```
