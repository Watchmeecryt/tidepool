<p><span className="tp-method tp-post">POST</span><code>{"/v0/faucet"}</code></p>

<Callout title="Tidepool extension">This endpoint is not part of the 1Click API. Do not call it on mainnet.</Callout>

Limits: one claim per address every 7 days across all faucet variants (NEAR wallet/intents/bridged and every other chain); six per IP per hour. Other chains: send `{"chain":"base","address":"0x…"}` (also eth, arb, sol, stellar, sui; btc and xrp answer 400 with the external faucet to use, since native BTC and XRP are never dripped). Bridged tokens into the verifier: `{"accountId":"alice.testnet","mode":"intents","assets":["sol"]}`. In `wallet` mode `drips` has one entry and `transactions` one transaction per token (all six NEAR test tokens by default); in `intents` mode the transfer is batched into one transaction per six tokens. The 200 sample below was recorded from a live `wallet` drip and is **shortened**: it lists two of the six tokens in `drips` and only the first mint in `transactions`. A full response lists every token (one `transactions` entry per token in `wallet` mode). See [Faucet](/docs/guides/faucet).

Drips Tidepool test tokens; the same faucet backs the dropdown on /docs/guides/faucet. NEAR (no chain): pass accountId; mode=wallet mints the six NEP-141 test tokens to the account; mode=intents credits them inside the Tidepool verifier. With mode=intents, assets also accepts chain aliases (sol, stellar, sui, base, arb, eth, bridged) that credit that chain's bridged test tokens to the intents balance: USDC and USDT 100 each, plus verifier-only test SOL (0.05) for sol and test XLM (5) for stellar and test SUI (0.5) for sui; bridged drips share the same 7-day per-address limit. Other chains: pass chain (eth, base, arb, bsc, sol, stellar or sui) and the address on that chain to send 100 test USDC and 100 test USDT there (ERC-20, SPL with token accounts created for you, Stellar classic assets, or Sui Move coins (no setup, any address); Stellar needs an existing account with trustlines to issuer GDXABUSRHP4YA5CELHLNJQ4M3TX2BSJ6PEMDFCG2RA4PQLAQLRMFFQAN). Native gas (ETH, SOL, XLM, SUI) is never dripped: use each chain's own faucet. Native BTC (testnet4) and native XRP are never dripped either: chain btc and chain xrp answer 400 and name the external faucet (CypherFaucet / testnet4.info for BTC, the official XRPL testnet faucet faucet.altnet.rippletest.net for XRP). one claim per account or address every 7 days across all variants; 6 per IP per hour.

**Operation id:** `TidepoolFaucet`

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl -X POST "https://www.usetidepool.tech/v0/faucet" \
  -H 'content-type: application/json' \
  -d '{
  "accountId": "alice.testnet",
  "mode": "wallet"
}'
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/faucet', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({
    "accountId": "alice.testnet",
    "mode": "wallet"
  }),
});
const data = await res.json();
```

</Tab>
</Tabs>

### Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `accountId` | string |  | NEAR testnet account. Required unless chain/address are set. |
| `mode` | "wallet" \\| "intents" |  |  |
| `assets` | string[] |  | Optional subset: asset ids, NEAR symbols, or (mode=intents) chain aliases sol, stellar, sui, base, arb, eth, bridged (btc and xrp are accepted but give nothing: native BTC and XRP are never dripped). Default: the six NEAR tokens. |
| `chain` | "base" \\| "arb" \\| "eth" \\| "sol" \\| "stellar" \\| "sui" |  | Chain to drip USDC and USDT on (Base Sepolia, Arbitrum Sepolia, Ethereum Sepolia, BSC Testnet, Solana devnet, Stellar testnet, Sui testnet). Omit for NEAR. btc and xrp are not drip chains: they answer 400 with the external faucet to use (native BTC and XRP are never dripped). |
| `address` | string |  | Address on that chain: 0x… (eth, base, arb, bsc), base58 (sol), G… (stellar) or 0x + 64 hex (sui). Required with chain. |

## Responses

### 200 Drip sent

```json
{
  "accountId": "alice.testnet",
  "mode": "wallet",
  "drips": [
    {
      "assetId": "nep141:usdc.tidepool-sandbox.testnet",
      "symbol": "USDC",
      "amount": "100"
    },
    {
      "assetId": "nep141:usdt.tidepool-sandbox.testnet",
      "symbol": "USDT",
      "amount": "100"
    }
  ],
  "transactions": [
    {
      "assetId": "nep141:usdc.tidepool-sandbox.testnet",
      "amount": "100",
      "txHash": "F6JiEXj2LSkzhAdGoBV5hBs5etTjdgNvvNsH72aBACcN",
      "explorerUrl": "https://testnet.nearblocks.io/txns/F6JiEXj2LSkzhAdGoBV5hBs5etTjdgNvvNsH72aBACcN"
    }
  ]
}
```

### 400 Bad request

```json
{
  "message": "accountId must be a NEAR testnet account id"
}
```

### 429 Rate limited

```json
{
  "message": "Rate limited: alice.testnet can use the faucet again after 2026-11-07T12:00:00.000Z (one claim per address every 7 days).",
  "available_at": "2026-11-07T12:00:00.000Z",
  "retryAfter": "2026-11-07T12:00:00.000Z",
  "retryAfterSeconds": 604800
}
```
