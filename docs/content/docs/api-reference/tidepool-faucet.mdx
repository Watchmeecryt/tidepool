<p><span className="tp-method tp-post">POST</span><code>/v0/faucet</code></p>

<Callout title="Tidepool extension">This endpoint is not part of the 1Click API. Do not call it on mainnet.</Callout>

Limits: one drip per account per mode per hour, six per IP per hour. Response lists all drips (trimmed here). See [Faucet](/docs/guides/faucet).

Drips every Tidepool test token to a NEAR testnet account. mode=wallet mints NEP-141 tokens to the account; mode=intents credits the account inside the Tidepool verifier. One drip per account and mode per hour; 6 per IP per hour.

**Operation id:** `TidepoolFaucet`

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl -X POST "https://www.usetidepool.tech/v0/faucet" \
  -H 'content-type: application/json' \
  -d '{
  "accountId": "alice.testnet",
  "mode": "wallet"
}'
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/faucet', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({
    "accountId": "alice.testnet",
    "mode": "wallet"
  }),
});
const data = await res.json();
```

</Tab>
</Tabs>
