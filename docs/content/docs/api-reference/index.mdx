Base URL: `https://tidepool-production-8594.up.railway.app` · Spec: [`/openapi.json`](/openapi.json) (1Click Swap API v0.1.10 shapes plus two Tidepool extensions).

All amounts are strings in the token's base units. Errors return `{ "message": "…" }` with HTTP 400, 404 or 429. CORS is open (`*`).
