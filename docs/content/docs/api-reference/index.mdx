Base URL: `https://www.usetidepool.tech` · Spec: [`/openapi.json`](/openapi.json) (the full 1Click Swap API v0.1.10 surface, plus two Tidepool extensions).

All amounts are strings in the token's base units. Errors on the swap, auth and account endpoints return `{ "message": "…" }` with HTTP 400 (bad input), 401 (`/v0/account/*` without a valid token), 404 (unknown deposit address), 429 (rate limited) or 503 (a bridge route is not configured, or its treasury is low); quote 400s also carry `hint`, `field` and `exampleRequest`. `/v0/orders` follows 1Click and returns JSON:API `{ "errors": [{ "status", "code", "title", "detail" }] }` (400, 401, 403, 404, 409 or 500). CORS is open (`*`).

## Authentication

Optional for swaps. Send any `X-API-Key: <anything>` or `Authorization: Bearer <anything>` to get the lower fee tier. See [Quotes](/docs/concepts/quotes#fees). `/v0/account/*` needs a free JWT from [`/v0/auth/authenticate`](/docs/api-reference/authenticate); `/v0/orders` needs a JWT or any `X-API-Key`.
