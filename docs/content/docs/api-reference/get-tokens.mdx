<p><span className="tp-method tp-get">GET</span><code>{"/v0/tokens"}</code></p>

Returns the six NEAR test tokens plus every live bridged token (USDC and USDT on Base, Arbitrum and Ethereum Sepolia; SOL, USDC and USDT on Solana devnet; XLM, USDC and USDT on Stellar testnet; SUI, USDC and USDT on Sui testnet; native BTC on Bitcoin testnet4; native XRP on the XRP Ledger testnet), with live USD prices. The example below is the **complete** live response (23 tokens on 2026-10-30). Each bridged route appears only while it is live. `ondoTokens` is accepted and ignored.

Retrieves a list of tokens currently supported by the 1Click API for asset swaps. Each token entry includes its blockchain, contract address (if available), price in USD, and other metadata such as symbol and decimals.

**Operation id:** `getTokens`

## Request

<Tabs items={['curl', 'JavaScript']}>
<Tab value="curl">

```bash
curl "https://www.usetidepool.tech/v0/tokens"
```

</Tab>
<Tab value="JavaScript">

```ts
const res = await fetch('https://www.usetidepool.tech/v0/tokens');
const data = await res.json();
```

</Tab>
</Tabs>
