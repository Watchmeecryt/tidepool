## What is trustless

- **Swap atomicity.** Settlement is one `execute_intents` call on the unmodified verifier. Either both `token_diff`s apply or neither does.
- **The verifier code.** Built unmodified from `near/intents` tag `defuse/v0.4.5`, hash checked live by `/v0/health`.
- **Auditability.** Every deposit, settlement and refund is a public testnet transaction listed in `/v0/status`.

## What you trust Tidepool for

- **Deposit addresses are custodial.** Their keys are derived on the server from a master seed. Tidepool could move funds sent to them. This is the same trust you give 1Click's deposit addresses.
- **One maker sets every price.** Tidepool's maker is the only solver. Prices follow CoinGecko plus a fixed fee, not a competitive market.
- **Liveness.** If the server is down, deposits wait. Funds are not lost; they are refunded once the worker runs again and the deadline has passed.
- **Token admin.** The six token contracts are owned by `privacei.testnet`, which can mint any amount and change minters. The root and maker accounts are minters.
- **Contract keys.** The token accounts still hold full-access keys controlled by the Tidepool deployer, so their code could be upgraded. Treat balances as test data.
- **The test bridges.** Bridged routes go through a trusted relayer run by Tidepool, testnet only. One relayer key sweeps EVM deposits, mints the bridged NEP-141s (through the root account) and releases EVM payouts from the vault. The Solana, Stellar, Sui, Bitcoin and XRP Ledger routes use Tidepool-held keys and a treasury in the same way. There are no proofs or light clients. See [Test bridges](/docs/guides/bridges).

## Limitations (v1)

- Testnets only: NEAR testnet, plus Base, Arbitrum and Ethereum Sepolia (native ETH ORIGIN_CHAIN deposits and DESTINATION_CHAIN payouts, capped at 0.006 ETH per swap), Solana devnet (SOL capped at 0.005 SOL per swap), Stellar testnet (XLM capped at 100 XLM per swap) Sui testnet (SUI capped at 0.005 SUI per swap), Bitcoin testnet4 (0.005 BTC), XRP Ledger testnet (XRP capped at 100 XRP per swap) through the custodial test bridges.
- No confidential settlement: `CONFIDENTIAL_INTENTS` types return 400 and `confidentiality` is ignored, because it runs on NEAR's private infrastructure, which isn't exposed to outside builders ([NEAR's Oct 27, 2026 update](https://docs.near-intents.org/changelog/entries/2026-10-27-1click-confidential.md)). See the [Roadmap](/docs/resources/roadmap).
- Single maker with finite inventory. Large quotes fail with `Not enough maker liquidity`.
- Faucet: one claim per address every 24 hours across all variants, six per IP per hour.
- Live quotes need a deadline between 60 seconds and 24 hours ahead.
- State is a JSON file on one server volume; there is no SLA.
