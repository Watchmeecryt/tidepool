Tidepool now covers the full public 1Click v0 surface on NEAR testnet, plus test bridges to Base Sepolia, Arbitrum Sepolia, Ethereum Sepolia, Solana devnet, Stellar testnet, Sui testnet, Bitcoin testnet4 and XRP Ledger testnet. See [Compatibility](/docs/resources/compatibility) for the differences that remain.

## Planned

Nothing is in progress. If you need something, say so. Demand decides the order.

| Feature | Shipped | Notes |
| --- | --- | --- |
| Signed intents: `/v0/generate-intent`, `/v0/submit-intent` | 2026-10-27 | `INTENTS`-deposit quotes. See [Generate intent](/docs/api-reference/generate-intent). |
| Limit orders: `/v0/orders` | 2026-10-27 | JSON:API. Filled by the Tidepool maker. See [Orders](/docs/api-reference/create-order). |
| `appFees` | 2026-10-27 | Fee transfers settle in the same `execute_intents` call as the swap. |
| `ANY_INPUT` + `/v0/any-input/withdrawals` | 2026-10-27 | See [Swap types](/docs/concepts/swap-types). |

| Faucet chain dropdown and bridged intents drips | 2026-10-29 | See [Faucet](/docs/guides/faucet). |

## Not planned

| Feature | Why |
| --- | --- |
| `CONFIDENTIAL_INTENTS` (deposit, refund and recipient type) | It depends on NEAR's private Confidential Intents infrastructure, which is not available on testnet. These types return 400 on Tidepool; the separate `confidentiality` parameter is accepted and ignored. Since [Oct 27, 2026](https://docs.near-intents.org/changelog/entries/2026-10-27-1click-confidential.md) mainnet 1Click settles every swap confidentially (`nearTxHashes` lists only shield/unshield); Tidepool swaps settle publicly and include the swap hash. Rely on `status`, not on a swap hash. Test it on mainnet with small amounts. |

Shipped work is recorded in the [Changelog](/docs/resources/changelog).
