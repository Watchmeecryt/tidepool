## Bridged EVM test tokens

These are listed in `/v0/tokens` with `blockchain` set to `base`, `arb` or `eth` and `contractAddress` set to the ERC-20. The NEP-141 side is a Tidepool token contract owned by `tidepool-sandbox.testnet` (the bridge account). Both sides are minted by Tidepool's testnet relayer; see [Test bridges](/docs/guides/bridges).

## Admin methods

| Method | Who | Effect |
| --- | --- | --- |
| `owner_id()` | view | Returns the owner. Currently `privacei.testnet` on all six. |
| `is_minter({ account_id })` | view | `true` for the owner and allowed minters. |
| `mint({ account_id, amount })` | owner or minter | Mints any amount. Used by the faucet. |
| `add_minter` / `remove_minter({ account_id })` | owner | Manage the minter allowlist. |
| `set_owner({ new_owner })` | owner | Transfers ownership and registers storage for the new owner. |

Current minters: `tidepool-sandbox.testnet` (wallet faucet) and `maker.tidepool-sandbox.testnet`.
