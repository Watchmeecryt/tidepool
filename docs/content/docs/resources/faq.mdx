<Accordions>
<Accordion title="Is this the official 1Click testnet?">No. Tidepool is a community-built sandbox that copies the 1Click API shape. It is not affiliated with NEAR or 1Click.</Accordion>
<Accordion title="Who fills my swap?">Tidepool's own maker, `maker.tidepool-sandbox.testnet`. It is the only solver, like a single market maker behind a swap app.</Accordion>
<Accordion title="Can I mint unlimited tokens?">No. The public faucet gives fixed amounts (for example 100 USDC) once per account per mode per hour, one drip per address per chain per hour, and six requests per IP per hour. Only the token owner and the two minter accounts can mint arbitrary amounts.</Accordion>
<Accordion title="Is there a web app?">Yes: the [Tidepool App](https://app.usetidepool.tech) is a swap and bridge UI for the testnet (token and chain picker, live quote, deposit address with QR and countdown, live status with explorer links, local history and a faucet). It is a plain client of this public API, with optional EVM and NEAR wallet connect. Testnet only.</Accordion>
<Accordion title="Do I need an API key?">No. Any `X-API-Key` or Bearer value is accepted and only lowers the fee tier.</Accordion>
<Accordion title="My status stays PENDING_DEPOSIT.">Check you sent the origin token (not another one) to the exact `depositAddress`, that NEAR `ORIGIN_CHAIN` deposits registered storage first, that Stellar and XRP deposits carry the `depositMemo` (the XRP Payment's `DestinationTag`), and that the deadline has not passed. Calling `/v0/deposit/submit` with your tx hash helps.</Accordion>
<Accordion title="I sent too little.">Status shows `INCOMPLETE_DEPOSIT`. Send the rest before the deadline, or wait and it is refunded with `PARTIAL_DEPOSIT`.</Accordion>
<Accordion title="I sent too much.">The swap uses `amountIn` and returns the excess in the same transaction.</Accordion>
<Accordion title="Which chains can I swap between?">NEAR testnet, plus Base Sepolia, Arbitrum Sepolia, Ethereum Sepolia, Solana devnet, Stellar testnet, Sui testnet, Bitcoin testnet4, XRP Ledger testnet through Tidepool's [test bridges](/docs/guides/bridges). Read the live list from `GET /v0/tokens`.</Accordion>
<Accordion title="Does the official SDK work?">Yes. `@defuse-protocol/one-click-sdk-typescript` 0.1.26 was tested with `getTokens`, `getQuote` and `getExecutionStatus`. Set `OpenAPI.BASE`.</Accordion>
<Accordion title="Can I run my own Tidepool?">The code is in a private repository today. Contact the maintainer for access.</Accordion>
<Accordion title="Is the verifier modified?">No. Its wasm hash matches the `defuse/v0.4.2` release and is checked on every `/v0/health` call.</Accordion>
</Accordions>
