## 2026-10-25 · New theme, light and dark modes, and a demo video

- The site and docs now use the same colours as NEAR Private OTC, in light and dark. Light mode has a cream background, ink text and a bronze accent. Dark mode has a warm charcoal background, cream text and a gold accent. The font is Geist, with Geist Mono for code. The design is plainer than before: no aurora or wave backdrop, flat cards with thin borders, and pill-shaped buttons.
- The theme follows your system setting by default. The toggle in the sidebar and nav saves your choice, and pages load in the right theme with no flash.
- The share images (`og.png` and the image for each docs page), favicons, app icons, the manifest and the browser `theme-color` all use the new colours. `/admin` follows your system theme.
- A new narrated demo video, recorded on the new theme, is on the [Introduction](/docs) page. It is served from `/videos/tidepool-demo.mp4` and supports range requests, so you can seek in it.

## 2026-10-25 · SEO and agent discoverability

- Every page now has a unique title and description, a canonical URL, Open Graph and Twitter card tags, and a 1200×630 share image. All of these are in the server-rendered HTML.
- New `robots.txt` (all crawlers allowed, including AI crawlers; `/admin` disallowed), `sitemap.xml` with `lastmod`, `site.webmanifest` and a full favicon set.
- JSON-LD structured data: Organization, WebSite and SoftwareApplication/WebAPI on the home page, and BreadcrumbList and TechArticle on docs pages.
- `llms.txt`, `llms-full.txt` and `AGENTS.md` now open with a short summary: what Tidepool is, the base URL, the quickstart and the faucet.
- The footer of the site and of every docs page says Tidepool is community-built and not affiliated with NEAR.

## 2026-10-25 · Testing failure cases guide and roadmap

- New guide: [Testing failure cases](/docs/guides/failure-cases). It was added in response to community feedback on Discord about expired quotes and under-deposits. It covers a partial deposit (`INCOMPLETE_DEPOSIT` → `REFUNDED` / `PARTIAL_DEPOSIT`), a late deposit (`REFUNDED` / `DEADLINE_PASSED`) and an overpay (`SUCCESS` with `refundedAmount`). Each case shows the real `/v0/status` JSON from testnet runs, with NearBlocks links for every deposit and refund.
- New runnable script `examples/failure-cases.mjs` (`partial`, `expired`, `overpay`, `errors`, `all`).
- New API error table for bad deadlines and unknown deposit addresses, plus integration tips (polling, `refundReason`, deadlines, idempotency).
- [Refunds](/docs/concepts/refunds) and [Status lifecycle](/docs/concepts/status-lifecycle) now link to the guide.
- New [Roadmap](/docs/resources/roadmap) page. It lists `appFees`, `ANY_INPUT`, `depositMode: MEMO`, Base Sepolia and Ethereum Sepolia test bridges, and `/v0/auth`-compatible endpoints as planned, pending v1 traction. `CONFIDENTIAL_INTENTS` is not planned. The feature-gap notes in Mainnet migration, Trust model and Quickstart link to it.

## 2026-10-24 · New domain and redesign

- Tidepool moved to [www.usetidepool.tech](https://www.usetidepool.tech). The API, docs, `openapi.json`, `llms.txt` and explorer links all use the new URL.
- Site and docs redesign: a deep-ocean palette, an aurora and wave hero, a display font, glass cards, and restyled code blocks and sidebar.

## 2026-10-24 · Docs v2 and token ownership

- New documentation site: concepts, lifecycle diagrams, an API reference generated from `openapi.json`, live faucet and status widgets, Copy Markdown / Open in ChatGPT or Claude on every page, `llms.txt` and `llms-full.txt`.
- Token contracts gained `set_owner`, `add_minter`, `remove_minter` and `is_minter`. Ownership of all six tokens moved to `privacei.testnet`. The root and maker accounts stay as minters, so the faucet is unchanged.
- `ORIGIN_CHAIN` deposits: gas top-up raised to 0.12 NEAR so the sweep never runs out of prepaid gas.
- `/v0/status`: duplicate `intentHashes` removed.

## 2026-10-24 · v1

- First public release: official verifier v0.4.2, six test tokens, faucet, maker, and the 1Click-shaped `/v0/tokens`, `/v0/quote`, `/v0/deposit/submit`, `/v0/status`.
- `EXACT_INPUT`, `EXACT_OUTPUT`, `FLEX_INPUT`; `ORIGIN_CHAIN` and `INTENTS` deposits.
