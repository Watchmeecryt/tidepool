<Callout type="success" title="No sign-up, no API key">
No sign-up, no API key. Call the API directly; any `X-API-Key` or `Bearer` value is accepted (it just selects the lower fee tier). Only `/v0/account/*` needs a token, which you get instantly by signing a message with your own wallet via `POST /v0/auth/authenticate`. It only ever shows that wallet's own data.
</Callout>

<Callout type="warn" title="Trust model: community-operated testnet">
Tidepool is a community-operated testnet environment, **not affiliated with NEAR, Defuse or 1Click**. Tidepool runs the only maker and derives the deposit-address keys on its server, so deposit addresses are custodial. Testnet only: **never send real assets** to a Tidepool address. See [Trust model](/docs/resources/trust-model).
</Callout>

## What is Tidepool?

Tidepool is a testnet version of the 1Click API: a free 1Click testnet endpoint at `https://www.usetidepool.tech` that uses the same endpoints and field names as mainnet 1Click. Use it as a 1Click API alternative while you develop and test, then switch the base URL to 1Click for production.

Tidepool gives you everything a 1Click swap needs, on testnet:

- **The official NEAR Intents verifier** (`defuse` v0.4.2, wasm byte-identical to the GitHub release) deployed at `verifier.tidepool-sandbox.testnet`.
- **Six test tokens**: USDC, USDT, wNEAR, wBTC, ETH and XAUT, with a public faucet.
- **A live maker** that quotes every pair from real CoinGecko prices and fills every quote by signing intents on the verifier.
- **The 1Click Swap API shape** (`/v0/tokens`, `/v0/quote`, `/v0/deposit/submit`, `/v0/status`), so the official SDK works by changing one base URL.
