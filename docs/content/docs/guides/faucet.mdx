## What you get per drip

| Token | Amount | Contract |
| --- | --- | --- |
| USDC | 100 | `usdc.tidepool-sandbox.testnet` (6 decimals) |
| USDT | 100 | `usdt.tidepool-sandbox.testnet` (6 decimals) |
| wNEAR | 40 | `wnear.tidepool-sandbox.testnet` (24 decimals) |
| wBTC | 0.001 | `wbtc.tidepool-sandbox.testnet` (8 decimals) |
| ETH | 0.03 | `eth.tidepool-sandbox.testnet` (18 decimals) |
| XAUT | 0.03 | `xaut.tidepool-sandbox.testnet` (6 decimals) |

Pass `"assets": ["USDC", "wNEAR"]` (symbols or asset ids) to drip only some tokens.

## Modes

| `mode` | Where tokens land | Needs |
| --- | --- | --- |
| `wallet` | NEP-141 wallet balance. Minted fresh by the root account, one `mint` tx per token. | The account must exist on testnet. Storage is registered automatically. |
| `intents` | Your intents balance inside the verifier. One `mt_batch_transfer` from the maker. | Nothing. Works for any account id, even one that does not exist yet. |

## Limits

- **One drip per account per mode per hour.** `alice.testnet` can take one `wallet` and one `intents` drip each hour.
- **Six drips per IP per hour.**
- Over the limit returns **HTTP 429** with the time you can retry.
- If a transfer fails, the limit is not consumed.

Supply is not capped, but the faucet can only mint these fixed amounts. Only the token owner (`privacei.testnet`) and the two allowed minters (`tidepool-sandbox.testnet`, `maker.tidepool-sandbox.testnet`) can call `mint`.

## API

```bash
curl -X POST https://www.usetidepool.tech/v0/faucet -H 'content-type: application/json' \
  -d '{"accountId":"alice.testnet","mode":"wallet"}'
```

See [POST /v0/faucet](/docs/api-reference/tidepool-faucet) for the full response.

## EVM testnets

Pass `chain` (`base`, `arb` or `eth`) and a `0x` `address` to mint test USDC and USDT on Base Sepolia, Arbitrum Sepolia or Ethereum Sepolia:

```bash
curl -X POST https://www.usetidepool.tech/v0/faucet -H 'content-type: application/json' \
  -d '{"chain":"base","address":"0xYourAddress"}'
```

You get 100 USDC and 100 USDT (6 decimals) on that chain, with the same limits (one drip per address per chain per hour, six per IP per hour). Gas ETH is **not** included; use the chain's public faucet. You can also call `faucet()` on the token contracts directly. Addresses are in each route guide under [Test bridges](/docs/guides/bridges).

## Solana devnet

`{"chain":"sol","address":"YourSolanaAddress"}` mints test USDC and USDT to your associated token accounts on Solana devnet (not SOL: bring your own devnet SOL; SOL swaps are capped at 0.005 SOL). See the [Solana devnet bridge](/docs/guides/bridge-solana-devnet).

## Stellar testnet

`{"chain":"stellar","address":"G..."}` pays test USDC and USDT (Tidepool's own classic assets) from the treasury to a Stellar testnet account. The account must already exist and trust both assets (a `changeTrust` operation for each); otherwise the faucet answers `400` and says which is missing. It does not drip XLM: get 10,000 test XLM from [Friendbot](https://friendbot.stellar.org). One drip per address per hour. See the [Stellar testnet bridge](/docs/guides/bridge-stellar-testnet).

<Callout type="warn">Test tokens have **no value**. The EVM test tokens are bridged only by Tidepool's own testnet relayer, not by any NEAR or 1Click bridge. Do not list or trade them anywhere.</Callout>
