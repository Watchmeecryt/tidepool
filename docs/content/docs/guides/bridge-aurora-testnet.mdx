## 1. Get tokens and gas

```bash
curl -X POST https://www.usetidepool.tech/v0/faucet -H 'content-type: application/json' \
  -d '{"chain":"aurora","address":"0xYourAddress"}'
```

This mints 100 test USDC and 100 test USDT on Aurora Testnet. The faucet is site-only, so claim on the [Faucet](https://app.usetidepool.tech/faucet) page (Aurora card). Gas is **not** included: get Aurora testnet ETH from the [Aurora faucet](https://aurora.dev/faucet), or bridge Sepolia ETH to Aurora Testnet with the Omni bridge.

## 2. Aurora Testnet → NEAR

```ts
const quote = await OneClickService.getQuote({
  dry: false, swapType: 'EXACT_INPUT', slippageTolerance: 100,
  originAsset: 'nep141:aur-0x38d81431b9f76d9699af7517040d5221d9dea252.tp-omft.testnet', // USDC on Aurora
  destinationAsset: 'nep141:wnear.tidepool-sandbox.testnet',
  amount: '10000000',                       // 10 USDC
  depositType: 'ORIGIN_CHAIN', refundTo: '0xYourAddress', refundType: 'ORIGIN_CHAIN',
  recipient: 'you.testnet', recipientType: 'DESTINATION_CHAIN',
  deadline: new Date(Date.now() + 30 * 60_000).toISOString(),
});
// quote.quote.depositAddress is a 0x address on Aurora Testnet. Send the ERC-20 there.
await OneClickService.submitDepositTx({ txHash: '0x…', depositAddress: quote.quote.depositAddress });
```

## 3. Anything → Aurora Testnet (Safe payouts)

Set `destinationAsset` to an `aur-` asset id and `recipient` to any `0x` address. Payouts are plain ERC-20 `transfer`s from the vault, so contract wallets such as a Safe receive them like any EOA (no callback, no gas needed on the recipient).

Status goes `PENDING_DEPOSIT → KNOWN_DEPOSIT_TX → PROCESSING → SUCCESS`, usually within a minute.
