## 1. Get tokens and gas

```bash
curl -X POST https://www.usetidepool.tech/v0/faucet -H 'content-type: application/json' \
  -d '{"chain":"eth","address":"0xYourAddress"}'
```

This mints 100 test USDC and 100 test USDT on Ethereum Sepolia. It is also in the dropdown on the [Faucet](/docs/guides/faucet) page. To get the bridged USDC and USDT into your NEAR intents balance instead, use `{"accountId":"alice.testnet","mode":"intents","assets":["eth"]}`. You can also call `faucet()` on either token contract yourself (once per hour per address). Gas is **not** included: get Ethereum Sepolia ETH from a [public faucet](https://www.alchemy.com/faucets/ethereum-sepolia).

**Native ETH (delivery only).** `nep141:eth.tp-omft.testnet` (18 decimals, like 1Click's `nep141:eth.omft.near`) pays out real Ethereum Sepolia ETH from the relayer to any `0x` address, so a fresh wallet can get a little gas along with USDC or USDT. It is **capped at 0.01 ETH per swap, payout or refund** (400 at quote time; 503 while the treasury is low), cannot be an `ORIGIN_CHAIN` deposit, and is not dripped by the faucet.

## 2. Ethereum Sepolia → NEAR

```ts
const quote = await OneClickService.getQuote({
  dry: false, swapType: 'EXACT_INPUT', slippageTolerance: 100,
  originAsset: 'nep141:eth-0x2e6ad9e6d59bb4585ea0e6762c3b637dde29dad2.tp-omft.testnet',
  destinationAsset: 'nep141:wnear.tidepool-sandbox.testnet',
  amount: '10000000',                       // 10 USDC
  depositType: 'ORIGIN_CHAIN', refundTo: '0xYourAddress', refundType: 'ORIGIN_CHAIN',
  recipient: 'you.testnet', recipientType: 'DESTINATION_CHAIN',
  deadline: new Date(Date.now() + 30 * 60_000).toISOString(),
});
// quote.quote.depositAddress is a 0x address on Ethereum Sepolia. Send the ERC-20 there:
// usdc.transfer(quote.quote.depositAddress, 10_000000n)
await OneClickService.submitDepositTx({ txHash: '0x…', depositAddress: quote.quote.depositAddress });
```

The relayer sweeps the deposit into the vault, mints the bridged NEP-141 and credits it to the verifier with a normal `ft_transfer_call`. The swap then settles exactly like a NEAR-only swap. Status goes `PENDING_DEPOSIT → KNOWN_DEPOSIT_TX → PROCESSING → SUCCESS`, usually within a minute.

## 3. NEAR → Ethereum Sepolia

Quote with `destinationAsset: 'nep141:eth-0x2e6ad9e6d59bb4585ea0e6762c3b637dde29dad2.tp-omft.testnet'`, `recipient: '0xYourAddress'` and `recipientType: 'DESTINATION_CHAIN'`, then deposit on NEAR as usual. The verifier `ft_withdraw`s the bridged token to the relayer, which calls `release` on the vault. Status stays `PROCESSING` until the Ethereum Sepolia payout confirms, then turns `SUCCESS` with the payout in `destinationChainTxHashes`.

Runnable: `EVM_PRIVATE_KEY=0x… EVM_CHAIN=eth RECIPIENT=you.testnet WITHDRAW=1 npm run evm-deposit` in [tidepool-examples](https://github.com/Watchmeecryt/tidepool-examples). It deposits USDC on the EVM chain, receives wNEAR on NEAR, and with `WITHDRAW=1` sends it back. Use a testnet-only key with a little gas ETH.

## Refunds

Refunds follow the same rules as NEAR-only swaps (`DEADLINE_PASSED`, `PARTIAL_DEPOSIT`, overpay). A refund of an EVM deposit with `refundType: "ORIGIN_CHAIN"` is paid back from the vault to `refundTo` on Ethereum Sepolia.
