## 1. Get tokens and gas

```bash
curl -X POST https://www.usetidepool.tech/v0/faucet -H 'content-type: application/json' \
  -d '{"chain":"base","address":"0xYourAddress"}'
```

This mints 100 test USDC and 100 test USDT on Base Sepolia. It is also in the dropdown on the [Faucet](/docs/guides/faucet) page. To get the bridged USDC and USDT into your NEAR intents balance instead, use `{"accountId":"alice.testnet","mode":"intents","assets":["base"]}`. You can also call `faucet()` on either token contract yourself (once per hour per address). Gas is **not** included: get Base Sepolia ETH from a [public faucet](https://docs.base.org/get-started/get-funds).

## 2. Base Sepolia → NEAR

```ts
const quote = await OneClickService.getQuote({
  dry: false, swapType: 'EXACT_INPUT', slippageTolerance: 100,
  originAsset: 'nep141:base-0x38d81431b9f76d9699af7517040d5221d9dea252.tp-omft.testnet',
  destinationAsset: 'nep141:wnear.tidepool-sandbox.testnet',
  amount: '10000000',                       // 10 USDC
  depositType: 'ORIGIN_CHAIN', refundTo: '0xYourAddress', refundType: 'ORIGIN_CHAIN',
  recipient: 'you.testnet', recipientType: 'DESTINATION_CHAIN',
  deadline: new Date(Date.now() + 30 * 60_000).toISOString(),
});
// quote.quote.depositAddress is a 0x address on Base Sepolia. Send the ERC-20 there:
// usdc.transfer(quote.quote.depositAddress, 10_000000n)
await OneClickService.submitDepositTx({ txHash: '0x…', depositAddress: quote.quote.depositAddress });
```

The relayer sweeps the deposit into the vault, mints the bridged NEP-141 and credits it to the verifier with a normal `ft_transfer_call`. The swap then settles exactly like a NEAR-only swap. Status goes `PENDING_DEPOSIT → KNOWN_DEPOSIT_TX → PROCESSING → SUCCESS`, usually within a minute.

## 3. NEAR → Base Sepolia

Quote with `destinationAsset: 'nep141:base-0x38d81431b9f76d9699af7517040d5221d9dea252.tp-omft.testnet'`, `recipient: '0xYourAddress'` and `recipientType: 'DESTINATION_CHAIN'`, then deposit on NEAR as usual. The verifier `ft_withdraw`s the bridged token to the relayer, which calls `release` on the vault. Status stays `PROCESSING` until the Base Sepolia payout confirms, then turns `SUCCESS` with the payout in `destinationChainTxHashes`.

Runnable: `EVM_PRIVATE_KEY=0x… EVM_CHAIN=base RECIPIENT=you.testnet WITHDRAW=1 npm run evm-deposit` in [tidepool-examples](https://github.com/zer0plugyut-afk/tidepool-examples). It deposits USDC on the EVM chain, receives wNEAR on NEAR, and with `WITHDRAW=1` sends it back. Use a testnet-only key with a little gas ETH.

## Refunds

Refunds follow the same rules as NEAR-only swaps (`DEADLINE_PASSED`, `PARTIAL_DEPOSIT`, overpay). A refund of an EVM deposit with `refundType: "ORIGIN_CHAIN"` is paid back from the vault to `refundTo` on Base Sepolia.
