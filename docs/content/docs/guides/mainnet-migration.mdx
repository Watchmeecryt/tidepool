Tidepool mirrors the 1Click request and response shapes, so most code moves unchanged. This checklist covers what does change.

<Steps>
<Step>
**Base URL.** Replace `https://www.usetidepool.tech` with `https://1click.chaindefuser.com`. With the SDK, delete the `OpenAPI.BASE = …` line.
</Step>
<Step>
**Real auth.** Get a real JWT from the 1Click partner portal and set it as `OpenAPI.TOKEN` / `Authorization: Bearer`. Tidepool accepts any value; mainnet does not. Keyless mainnet calls pay an extra fee.
</Step>
<Step>
**Real asset ids.** Load ids from `GET /v0/tokens` at runtime. Never hardcode `nep141:*.tidepool-sandbox.testnet`; those contracts exist only on testnet.
</Step>
<Step>
**Chains.** Tidepool already uses the same multi-chain deposit flow as mainnet: each quote returns a deposit address on the origin chain (NEAR, Ethereum, Base, Arbitrum, Solana, Bitcoin, Stellar, Sui and XRP Ledger testnets), with a memo on chains that need one. Code you wrote for it carries over unchanged. On mainnet, switch your wallets and RPCs to mainnet, make sure `refundTo` and `recipient` are valid mainnet addresses, and read the supported `blockchain` values from `GET /v0/tokens`, since mainnet lists more chains than Tidepool.
</Step>
<Step>
**Features Tidepool lacks.** `confidentiality` is accepted but ignored on Tidepool, and the `CONFIDENTIAL_INTENTS` deposit, refund and recipient types return 400; test them on mainnet with small amounts. Mainnet 1Click now settles every swap confidentially ([NEAR's Oct 27, 2026 update](https://docs.near-intents.org/changelog/entries/2026-10-27-1click-confidential.md)), so `nearTxHashes` lists only the shield and unshield transactions, while Tidepool includes the swap's own hash; confidential settlement runs on NEAR's private infrastructure, which isn't exposed to outside builders. Key your code on `status`, not on a swap hash. JWTs from Tidepool's `/v0/auth` do not work on mainnet, so get a mainnet key. What is planned for Tidepool is on the [Roadmap](/docs/resources/roadmap).
</Step>
<Step>
**Prices and timing.** Mainnet quotes come from competing solvers and settle cross-chain, so `timeEstimate` can be minutes. Keep your polling loop tolerant of long `PROCESSING` periods.
</Step>
<Step>
**Ignore Tidepool-only fields.** Drop any use of `tidepool.explorer`, `tidepool.note`, `/v0/faucet` and `/v0/health`.
</Step>
</Steps>

<Callout type="warn">Always confirm the current mainnet API in the official 1Click documentation before shipping. Tidepool tracks OpenAPI v0.1.10 and may lag behind.</Callout>
